# Изменения в проекте

Перед изменением опишите проблему и ожидаемое поведение в issue. Для небольшой правки можно сразу открыть pull request.

1. Создайте отдельную ветку.
2. Внесите изменение и обновите документацию, если меняется поведение.
3. Для серверной логики добавьте проверку, которая воспроизводит проблему.
4. Запустите `python -m unittest discover -s tests -v` и `node --check web/app.js`.
5. В pull request укажите, что изменилось и как это проверить.

Не добавляйте в репозиторий базы, пароли, токены и локальные настройки редактора.
