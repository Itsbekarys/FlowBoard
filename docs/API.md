# HTTP API

Все ответы API — JSON в UTF-8. Ошибки имеют вид `{"error":"Описание"}`. Авторизации в локальной версии нет.

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/api/health` | Состояние сервера |
| GET | `/api/state` | Проекты, задачи и последние 20 событий |
| POST | `/api/projects` | Создание проекта, код 201 |
| POST | `/api/tasks` | Создание задачи, код 201 |
| PATCH | `/api/tasks/{id}` | Частичное изменение задачи |
| DELETE | `/api/tasks/{id}` | Удаление задачи |

Проект: `name` — обязательная строка до 80 символов, `description` — до 500.

Пример задачи:

```json
{
  "project_id": 1,
  "title": "Подготовить релиз",
  "description": "Проверить основной сценарий и обновить документацию",
  "status": "todo",
  "priority": "high",
  "assignee": "Анна",
  "due_date": "2026-12-01"
}
```

Обязательны `project_id` (целое число, существующий проект) и `title` (до 160 символов). Описание — до 5000, исполнитель — до 80. Дата — `YYYY-MM-DD` либо пустая строка.

Статусы: `todo`, `progress`, `review`, `done`. Приоритеты: `low`, `medium`, `high`. Значения по умолчанию — `todo` и `medium`. При PATCH достаточно передать изменяемые поля.

Неверные данные возвращают 400, отсутствующая задача или маршрут — 404, ошибка базы — 500. Максимальный размер тела запроса — 64 КиБ. Даты событий записываются SQLite в UTC; сроки задач — календарные даты без часового пояса.
